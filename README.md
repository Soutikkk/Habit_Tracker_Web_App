# 🌱 Habit Tracker Web App

A simple, modern, and user-friendly **Habit Tracker Web App** that helps users build consistent habits, track daily progress, and stay motivated.

## ✨ Features

- 📅 **Daily Habit Tracking** — Mark habits as completed for each day.
- ➕ **Add Habits** — Create and manage personal habits.
- ✏️ **Edit & Delete** — Update or remove habits easily.
- 🔥 **Habit Streaks** — Track consecutive days of completing habits.
- 📊 **Progress Tracking** — View overall habit completion and progress.
- 🗓️ **Calendar View** — See your habit history across different dates.
- 📱 **Responsive Design** — Works smoothly on desktop, tablet, and mobile.
- 💾 **Persistent Data** — Keep your habit progress saved between sessions.
- 🎨 **Clean UI** — Minimal and intuitive interface for distraction-free tracking.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **UI:** Responsive modern web design
- **Storage:** Local Storage
- **Version Control:** Git & GitHub
